# Skill 藏書（23 本）

> 🧭 [課程地圖](../README.md)｜[遊戲版：Skill 圖書館](https://bai-collab.github.io/llm_teach/world/)（第一島西邊的橋）

本工作區登錄的教學相關 skill 原檔，可以直接複製到自己的 AI 工具中參考使用。每份只附 `SKILL.md`；部分 skill 原本還有範本、參考資料等附屬檔，未一併收錄。

## 教案與評量

| Skill | 用途 | 什麼時候用 |
|---|---|---|
| [教案撰寫](lesson-plan-authoring/SKILL.md) | 依課綱、學生、節數、科技與評量條件寫教案，讓學習目標、活動與評量彼此對齊。 | 要寫一份新教案時 |
| [數位學習精進教案](digital-learning-lesson-plan/SKILL.md) | 數位學習精進教案：先選定送件格式，再寫平台證據、師生操作、學習證據、隱私說明與備案。 | 要送數位學習精進計畫時 |
| [教案差異化教學](lesson-differentiation/SKILL.md) | 以既有教案為底，替不同程度的學生分層支持，核心目標與標準不變。 | 教案寫好、要照顧學生差異時 |
| [試題命題](item-authoring/SKILL.md) | 依指標與來源命題，每題附答案、解析與人工審查欄位，可整理成題庫。 | 要出評量題或建題庫時 |
| [臆測五階段](conjecturing-five-stage/SKILL.md) | 把數學單元改成臆測五階段：造例、提出猜想、效化、一般化、證實；附造例卡、猜想池、反例與評量規準。 | 想讓學生自己發現數學性質時 |

## 闖關與遊戲

| Skill | 用途 | 什麼時候用 |
|---|---|---|
| [可玩世界備課](playable-world-prep/SKILL.md) | 先判斷教材值不值得做成可玩探究頁、核對事實，再把製作交給合適的 skill。 | 想把一課做成可以玩的之前 |
| [教材轉闖關遊戲](material-to-quest-game/SKILL.md) | 把教材轉成實體或網頁闖關規格：學習機制、關卡、回饋、素材、可及性與試玩。 | 要把教材做成闖關時 |
| [教育 Web 教學遊戲工作流](educational-web-game-workflow/SKILL.md) | 從教學規格、素材、網頁實作到驗證，一路編排完整的教育網頁遊戲。 | 闖關規格確定、要真的做成網頁時 |
| [教育卡牌遊戲設計與製作](educational-card-game/SKILL.md) | 把教材設計成網頁卡牌遊戲，含教師引導、規則、可及性、試算表保存與教師查分。 | 想做卡牌遊戲時 |
| [學習者行為與挑戰驗收](learner-behavior-game-review/SKILL.md) | 用學生實際操作的證據審查遊戲：挑戰階梯、答案洩漏、錯誤恢復；先檢查畫面結構，再實際操作。 | 遊戲做好、要驗收時 |

## 美術與 3D

| Skill | 用途 | 什麼時候用 |
|---|---|---|
| [闖關遊戲 Three.js 導入](quest-threejs-adoption/SKILL.md) | 在闖關遊戲中逐步加入 Three.js 3D，作答與學習狀態仍留在網頁層。 | 想讓闖關有 3D 畫面時 |
| [圖片轉 3D 場景](image-to-3d-scene/SKILL.md) | 把一張場景圖片重建成可環繞的 Three.js 3D 展示頁，用截圖比對到可以公開。 | 手上有參考圖、想做 3D 場景時 |
| [文字造獸](text-to-creature/SKILL.md) | 一句話生成可用在遊戲裡的 3D 生物（含骨架與動畫），用不知情的盲讀剪影做品管。 | 需要 3D 角色或生物時 |
| [程序化場景共用世界與量測迭代工作流](procedural-world-field-metrics-workflow/SKILL.md) | 程序化場景的共用世界欄位、材質與效能量測，讓視覺迭代有可回溯的證據。 | 3D 場景要反覆調整時 |
| [美工與分鏡設計](visual-art-storyboard/SKILL.md) | 規劃美術方向、角色、場景與素材提示詞，需要時加上八格分鏡。 | 需要角色、場景或分鏡時 |
| [Pixel AI 美術提示詞祕書](pixel-ai-secretary/SKILL.md) | 產生同一個角色的像素風 AI 祕書提示詞包，維持角色一致。 | 需要一致的像素風角色時 |
| [皮影戲網頁電影](shadow-movie/SKILL.md) | 把故事、劇本與分鏡做成傳統皮影戲風格的網頁電影。 | 想用故事動畫講課文或歷史時 |

## 寫作與協作

| Skill | 用途 | 什麼時候用 |
|---|---|---|
| [AI 創作協作循環](creative-collaboration-loop/SKILL.md) | 發散、收斂各兩輪的 AI 協作；每一步先決定 AI 要替代、加速、擴張還是挑戰。 | 構想還不清楚、想跟 AI 一起發想時 |
| [海明威寫作法](hemingway-writing/SKILL.md) | 去掉副詞與抽象形容，用具體可見的畫面寫作。 | 文章、講稿想更有畫面感時 |

## 解說與工具

| Skill | 用途 | 什麼時候用 |
|---|---|---|
| [AI 文件 Markdown 轉換](document-to-markdown-ingestion/SKILL.md) | 先把 PDF、Word、簡報轉成 Markdown 再讓 AI 讀，讀得準、也比較省；要核對版面或格式時才看原檔。 | 讀課本、手冊、會議資料之前 |
| [圖解先行](explain-visual/SKILL.md) | 解釋機制、流程或狀態時，先給最小的一張圖，文字只補圖說不出的。 | 要把概念講清楚時 |
| [網頁版面拓樸分析](web-layout-topology-analysis/SKILL.md) | 做網頁或遊戲前先規劃版面區塊，避免重疊、遮擋與點擊衝突。 | 動手寫網頁或遊戲之前 |
| [教師工作台建立](teacher-workspace-ui/SKILL.md) | 建立教師工作台：找學生、看作答紀錄、請 AI 分析，並集中管理連線設定。 | 想看全班的學習紀錄時 |

## 依目的的建議順序

由 AI 依各 skill 的說明預先排好，可依需要調整。

**寫一份新教案**

1. [AI 文件 Markdown 轉換](document-to-markdown-ingestion/SKILL.md)：先讓 AI 讀懂課本與教師手冊
2. [教案撰寫](lesson-plan-authoring/SKILL.md)：寫出目標、活動、評量對齊的教案
3. [圖解先行](explain-visual/SKILL.md)：替關鍵概念配一張圖
4. [試題命題](item-authoring/SKILL.md)：出評量題
5. [教案差異化教學](lesson-differentiation/SKILL.md)：替不同程度的學生分層

**數位學習精進教案送件**

1. [AI 文件 Markdown 轉換](document-to-markdown-ingestion/SKILL.md)：讀懂送件格式與課本
2. [數位學習精進教案](digital-learning-lesson-plan/SKILL.md)：寫精進教案與平台證據
3. [試題命題](item-authoring/SKILL.md)：準備學習成效評量
4. [教師工作台建立](teacher-workspace-ui/SKILL.md)：收集與查看學習紀錄

**數學臆測教學**

1. [AI 文件 Markdown 轉換](document-to-markdown-ingestion/SKILL.md)：讀懂數學單元
2. [臆測五階段](conjecturing-five-stage/SKILL.md)：改寫成臆測五階段
3. [教案差異化教學](lesson-differentiation/SKILL.md)：替不同程度的學生分層
4. [試題命題](item-authoring/SKILL.md)：出檢核學習的題目

**把教材做成闖關遊戲**

1. [可玩世界備課](playable-world-prep/SKILL.md)：先判斷值不值得做、核對事實
2. [教材轉闖關遊戲](material-to-quest-game/SKILL.md)：寫出闖關規格
3. [網頁版面拓樸分析](web-layout-topology-analysis/SKILL.md)：規劃畫面版面
4. [美工與分鏡設計](visual-art-storyboard/SKILL.md)：規劃角色與場景
5. [教育 Web 教學遊戲工作流](educational-web-game-workflow/SKILL.md)：做成網頁遊戲
6. [學習者行為與挑戰驗收](learner-behavior-game-review/SKILL.md)：用學生操作驗收

**讓闖關加入 3D**

1. [闖關遊戲 Three.js 導入](quest-threejs-adoption/SKILL.md)：決定 3D 放在哪裡、作答留在網頁層
2. [圖片轉 3D 場景](image-to-3d-scene/SKILL.md)：從參考圖做 3D 場景
3. [文字造獸](text-to-creature/SKILL.md)：做 3D 角色或生物
4. [程序化場景共用世界與量測迭代工作流](procedural-world-field-metrics-workflow/SKILL.md)：反覆調整並量測
5. [學習者行為與挑戰驗收](learner-behavior-game-review/SKILL.md)：驗收學生實際操作

**做教育卡牌遊戲**

1. [教育卡牌遊戲設計與製作](educational-card-game/SKILL.md)：設計卡牌規則與網頁
2. [美工與分鏡設計](visual-art-storyboard/SKILL.md)：規劃卡面美術
3. [Pixel AI 美術提示詞祕書](pixel-ai-secretary/SKILL.md)：做一致的像素風角色
4. [學習者行為與挑戰驗收](learner-behavior-game-review/SKILL.md)：用學生操作驗收

**把概念講清楚（圖解、動畫）**

1. [圖解先行](explain-visual/SKILL.md)：先畫一張最小的圖
2. [AI 創作協作循環](creative-collaboration-loop/SKILL.md)：跟 AI 發想表現方式
3. [皮影戲網頁電影](shadow-movie/SKILL.md)：做成故事動畫

**跟 AI 一起寫文章或計畫**

1. [AI 創作協作循環](creative-collaboration-loop/SKILL.md)：先發散再收斂
2. [海明威寫作法](hemingway-writing/SKILL.md)：把文字寫得有畫面
3. [圖解先行](explain-visual/SKILL.md)：重點配圖
