跟 AI 一起工作：給老師的四單元課程

從「老師當導演」開始，到為什麼要換一家 AI 審查、本工作區的規則怎麼運作，最後動手改造工具。每個單元先看動畫，再讀講義；動畫都可以逐段停下來解說。

遊戲版AI 協作群島操控 3D 老師走過四座島：和 AI 小幫手聊天、翻過山脊跳出局部解、踩亮流程石板、在 Hook 閘門擋下危險動作；西邊還有 Skill 圖書館，選目的就幫你排好要用的 skill。開始探索 ›
一

認識 AI 協作

所有老師約 15 分鐘

學完能說出：老師在 AI 協作裡扮演導演；AI 可以加快速度、協助發想、分析、批判、整理。

  1. 動畫老師當導演AI 五種角色與備課流程123 秒
  2. 動畫教師儀表板導覽看懂全班作答，再請 AI 分析60 秒
  3. 動畫闖關教材製作用 Claude Code 做出 2D＋3D 關卡92 秒

課堂提問：你下一個單元，最想請 AI 扮演五種角色中的哪一種？為什麼？

二

為什麼要這樣管 AI

觀念約 30 分鐘

學完能說出：模型外面為什麼需要一層 Harness；為什麼同家族做的要交給不同家族審查。

  1. 講義01 什麼是 Harness上下文、工具、護欄、狀態、驗證講義 01
  2. 動畫為什麼要換家審查3D 答案地形：局部解與盲點100 秒
  3. 講義07 AI Agent 架構 V4.1Harness → Agent → 核心循環 → Hooks講義 07

課堂提問：你自己檢查自己的作業時，最容易漏掉什麼？換別人看會不同嗎？

三

本工作區怎麼做

實務約 40 分鐘

學完能說出：一件任務從分類、路線圖、老師核准、派工到驗證的完整流程，以及 Skill 怎麼讓流程可重複。

  1. 動畫本工作區的 Harness十段規則總覽110 秒
  2. 講義02 本機 HarnessAdaptive Loop、Route Plan、分工、驗證預算講義 02
  3. 講義03 eduHarness SkillSkill 套件與用途 → 工作流程講義 03
  4. 講義04 eduHarness_Nooa雲端版與 Registry v3講義 04

課堂提問：你的備課流程中，哪一步最需要「老師核准」才能往下走？

四

動手改造工具

進階・開發者約 40 分鐘

學完能說出：Hook 怎麼在事件管線中插入檢查；還有哪些 LLM 專案可以拿來當案例。

  1. 講義05 Claude Code Mod Hook 流程prompt-optimizer 拆解，附練習講義 05
  2. 講義06 延伸專案瀏覽器端模型、教師工作台等講義 06
  3. 動畫程式變成神經網路？拆解 Handwiredif、迴圈改寫成電路，精確與梯度的前提134 秒

課堂提問：如果要寫一個 hook 擋住你最怕 AI 犯的錯，你會擋什麼？
