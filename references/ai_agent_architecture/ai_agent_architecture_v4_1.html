HARNESS｜最外層控制與執行框架
包住整個 Agent，負責調度、政策、執行環境、生命週期與觀測。
Layer 1
Orchestration任務／Agent／Skill 調度
Orchestration

決定任務如何拆分、由哪個 Agent、Skill 或 Tool 執行，以及失敗後要重試、fallback、轉交或停止。

Policy & Guardrails權限、安全、Human Gate
Policy & Guardrails

規範權限、安全、資料邊界、Human Gate、工具限制與失敗政策。

RuntimeSession／Sandbox／Context
Runtime

提供 session、sandbox、context、狀態與運算資源。Harness 通常在這一層管理 Agent 的執行環境。

Eval · Trace · Logs評估、追蹤與稽核
Eval · Trace · Logs

保存 Agent 的執行軌跡、工具呼叫、錯誤、成本與結果，協助品質評估與除錯。

AGENT｜處理任務的智慧代理
Harness 管整體運作；Agent 負責解決使用者任務。
Layer 2
🎯 User Goal使用者真正想完成什麼？
🎯 User Goal

整個系統的起點。Planner、Reasoning、Skill 與 Tool 都應服務這個目標，而不是為了使用某個工具而硬套流程。

→
1. Planner拆解任務、安排步驟
1. Planner

把目標拆成可執行的步驟。遇到新的 Observation 時，也可能重新規劃，而不是只在最開始執行一次。

→
2. Reasoning判斷目前應採取什麼策略
2. Reasoning

根據 User Goal、Memory、目前狀態、限制與 Observation，判斷下一步最適合做什麼。

CONTEXT / STATE
🧠 Memory短期／工作／長期記憶
🧠 Memory

Memory 不是孤立資料庫。它持續提供短期上下文、工作狀態與較長期資訊給 Reasoning 與核心循環使用。

提供上下文 →
Agent 核心循環Layer 3
① Think理解問題、整合上下文
① Think

讀取目前狀態與上下文，理解問題、分析資訊並形成下一步決策。

② Act決定下一個行動
② Act

決定要做什麼。可能直接呼叫 Tool，也可能先選擇適合的 Skill，由 Skill 引導後續步驟。

③ Action Input準備工具或技能參數
③ Action Input

把自然語言決策轉成 Tool 或 Skill 可以使用的結構化輸入，例如 query、JSON、檔案路徑或函式參數。

④ Observe讀取工具／環境結果
④ Observe

取得 Tool、MCP 或外部環境回傳的結果，再送回下一輪 Think，形成循環。

Think → Act → Action Input → Observe → Think ↻
CAPABILITY / EXECUTION
Act → Skill
🧩 Skill封裝「這類任務怎麼做」
🧩 Skill

封裝「某類任務應該怎麼做」的程序、知識、規則與工作流，例如文獻分析 Skill、簡報製作 Skill。它比單一 Tool 更高階。

↓ 編排／呼叫
🔧 Tool真正執行搜尋、程式、檔案等動作
🔧 Tool

真正執行外部操作，例如搜尋、讀寫檔案、資料分析、執行程式或寄送訊息。

↓ 外部連接
🔌 MCP外部工具／資源標準連接方式之一
🔌 MCP

Model Context Protocol 讓 Host／Agent 以標準方式連接外部 Tools、Resources 或 Services。MCP 是一種連接方式，不代表所有 Tool 都必須透過 MCP。

🪝 Hooks｜Harness 對生命週期的介入點
Hook 不是 Agent 固定流程的一步，而是在特定事件發生時插入檢查、轉換、紀錄或治理邏輯。
Pre-Agent開始前
Pre-Agent

Agent 啟動前介入，例如載入 context、驗證權限、準備環境或套用政策。

Pre-Tool工具前
Pre-Tool

Tool 執行前介入，例如參數驗證、安全檢查、權限確認或 Human Gate。

Post-Tool工具後
Post-Tool

Tool 執行後介入，例如驗證結果、整理輸出、記錄 log 或壓縮內容。

Error Hook發生異常
Error Hook

遇到錯誤時觸發，例如重試、fallback、切換工具、通知使用者或停止流程。

Pre-Compact上下文壓縮前
Pre-Compact

Context 壓縮之前介入，例如保存重要狀態、摘要必要資訊。是否存在此 Hook 取決於特定 Harness 實作。

Post-Agent任務完成後
Post-Agent

Agent 完成任務後介入，例如最終驗證、寫入紀錄、輸出後處理或觸發後續任務。

♻️ Reflection / Evaluation檢查結果是否達標，必要時重新規劃或執行
♻️ Reflection / Evaluation

檢查目前結果是否符合 User Goal。若不足，可修正策略、換 Skill、換 Tool，甚至重新回到 Planner。

↩
Feedback Loop
可回到 Planner、Reasoning 或核心循環，不是只能一路往下。
✅ Final Answer自然語言回答
✅ Final Answer

直接呈現給使用者的自然語言回覆，例如解釋、建議、摘要或決策結果。

📦 Artifact網頁／文件／簡報／程式／資料成果
📦 Artifact

Agent 也可以產出可持續使用的網頁、簡報、文件、程式、圖表、資料檔等成果。
